B. Von Neumann Architecture, System Buses & Instruction Cycle

Register Full Name Exact Exam Role
PC Program Counter Holds the memory address of the NEXT instruction to fetch.
IR Instruction Register Holds the current instruction being decoded/executed by CU.
MAR Memory Address Register Drives the unidirectional Address Bus with target RAM address.
MDR / MBR Memory Data / Buffer Register Buffers data words moving over the bidirectional Data Bus.
SP / BP Stack Pointer / Base Pointer Tracks top of call stack & current stack frame (function calls, interrupts, local vars).
PSW / FLAGS Program Status Word Stores status bits: Zero (Z), Sign (S), Carry (C), Overflow (V), Parity (P), Interrupt Enable (IE).

C. RISC vs. CISC & I/O Transfer Modes (Polling vs. Interrupt vs. DMA)

Parameter RISC (Reduced Instruction Set) CISC (Complex Instruction Set)
Instruction Format Fixed-length instructions; simple decoding; easy pipelining Variable-length instructions; complex multi-cycle ops
Memory Access Load/Store architecture (ALU operates only on registers) Memory-to-memory ALU instructions supported
Control Unit & Registers Hardwired CU; large register file (32+ registers) Microprogrammed CU; fewer registers; many addressing modes
Examples ARM, RISC-V, MIPS, Apple Silicon (M-series) Intel x86 / AMD64 (internally decodes CISC into RISC μops!)
  • Programmed I/O (Polling): CPU repeatedly checks device status flag in a busy-wait loop → wastes CPU cycles.
  • Interrupt-Driven I/O: Device raises an IRQ when ready; CPU saves context (PC/PSW on stack) and runs ISR → still transfers 1 word at a time via CPU.
  • DMA (Direct Memory Access): A dedicated DMA controller transfers bulk blocks directly between I/O device and RAM bypassing the CPU, interrupting CPU only once at completion. Modes: Burst Mode (DMA holds bus until entire block completes) and Cycle Stealing (DMA steals 1 bus cycle per word, letting CPU interleave).

Guaranteed Paper III MCQs

A. Signed Integer Representations (n-bit)

Format Exact Range (n-bit) 8-bit Range Zeros Exam Traps & Rules
Unsigned 0 to 2^n - 1 0 to 255 1 Overflow occurs iff Carry-out from MSB = 1.
Sign-Magnitude -(2^(n-1)-1) to +(2^(n-1)-1) -127 to +127 2 (+0, -0) Used in IEEE 754 mantissa sign bit, NOT integer ALU.

B. Binary, Character & Error-Control Codes

Code / Standard Width / Structure Key Properties & Formulas
BCD (8421) 4 bits per decimal digit Weighted code; 1010–1111 (10–15) are invalid states. Used in decimal financial hardware.
Excess-3 (XS-3) BCD + 0011 (+3) Unweighted, self-complementing code (9's complement = bitwise 1's complement).
Gray Code Unit-distance (reflected) Adjacent values differ by exactly 1 bit. Binary → Gray: G_i = B_i ⊕ B_(i+1) (MSB unchanged).
ASCII / EBCDIC / UTF-8 ASCII: 7-bit (128)
EBCDIC: 8-bit (IBM)
UTF-8: 1–4 bytes		 '0'=48, 'A'=65, 'a'=97. UTF-8 is variable-width & 100% backward-compatible with 7-bit ASCII.
Hamming Distance & Code Parity bits at positions 1, 2, 4, 8... (2^k) Detect t errors: d_min ≥ t + 1. Correct t errors: d_min ≥ 2t + 1.
Minimum parity bits r for m data bits: 2^r ≥ m + r + 1.

2.3 IEEE 754 Floating-Point Standard & Financial Precision Trap

High 2-Mark Yield
IEEE 754 Format Total Bits Sign Exponent (Bias) Mantissa Primary Use
Half (FP16) 16-bit 1 5 (Bias 15) 10 GPU graphics & mixed-precision AI inference
BFloat16 (Brain Float) 16-bit 1 8 (Bias 127) 7 Deep Learning training (same dynamic range as FP32!)
Single (FP32 / float) 32-bit 1 8 (Bias 127) 23 Standard scientific & graphics computation (~7 decimal digits)
Double (FP64 / double) 64-bit 1 11 (Bias 1023) 52 High-precision engineering (~15–17 decimal digits)
Banking IT Trap: Why CBS Never Uses IEEE 754 Binary Float for Money Decimal fractions like 0.1 and 0.2 are non-terminating repeating fractions in binary, causing 0.1 + 0.2 = 0.30000000000000004. Core banking ledgers therefore store monetary balances using Fixed-Point Decimal types (SQL DECIMAL(18,2), Java BigDecimal, Python Decimal) or scaled integer paise.

L1 / L2 / L3 Cache SRAM (6 Transistors, no refresh) 1–15 ns Yes Very high • KB to tens of MB
Main Memory (RAM) DRAM (1T1C capacitor, periodic refresh) 50–80 ns Yes Moderate • GB to TB (DDR4/DDR5)

ROM & Flash Family + Cache Write & Mapping Rules

  • ROM Evolution: PROM (one-time fuse burn) → EPROM (erased by UV light through quartz window) → EEPROM (electrically erasable byte-by-byte) → Flash (electrically erasable block-by-block). NOR Flash supports Execute-In-Place (XIP) for firmware/UEFI; NAND Flash provides high density for SSDs (SLC > MLC > TLC > QLC in endurance/speed).
  • Locality of Reference: Temporal Locality (reusing recently accessed data soon, e.g., loop index) and Spatial Locality (accessing nearby contiguous addresses, e.g., array scan—exploited by fetching entire cache lines/blocks).
  • Cache Write Policies: Write-Through updates both Cache and RAM simultaneously (simple, always consistent, higher bus traffic) vs. Write-Back updates only Cache and sets a Dirty Bit, flushing to RAM only upon eviction (faster, less bus traffic).
  • Cache Address Bit Split (Total Physical Address = Tag + Index + Block Offset): • Block Offset = log2(Block Size).
    • Direct Mapped: Index = log2(Number of Cache Lines); Tag = AddrBits - Index - Offset.
    • k-Way Set Associative: Sets = Total Lines / k; Index = log2(Sets).
    • Fully Associative: Index = 0 (no index field; compares Tag against all lines in parallel via CAM).

B. Combinational vs. Sequential Building Blocks

Circuit Type Core Equation / Specification

Multiplexer (MUX) Combinational 2^n data inputs, n select lines, 1 output. Universal combinational circuit (any n-var Boolean function fits in a 2^(n-1):1 MUX).

D & T Flip-Flops Sequential D (Delay): Q(t+1) = D (used in Registers & Shift Registers). T (Toggle): Q(t+1) = T ⊕ Q (used in Binary Counters; n-bit counter has 2^n states, MOD-2^n).

2.6 Worked Exam Numericals (8 Step-by-Step Problems)

Guaranteed 2-Mark Scoring Zone
Numerical 1: Hexadecimal Fractional Conversion Problem: Convert (2F.A)_16 to Binary and Decimal.
Binary (4 bits/hex digit): 2 = 0010, F = 1111, A = 1010 → (00101111.1010)_2.
Decimal: 2×16^1 + 15×16^0 + 10×16^-1 = 32 + 15 + 10/16 = 47 + 0.625 = 47.625.
Numerical 2: 8-bit 2's Complement Addition & Signed Overflow Problem: Compute (-45) + (-90) in 8-bit 2's complement and verify overflow.
Step 1: +45 = 0010 1101 → 2's comp = 1101 0011. +90 = 0101 1010 → 2's comp = 1010 0110.
Step 2: 1101 0011 + 1010 0110 = (1) 0111 1001. Here Carry-in to MSB = 0, Carry-out from MSB = 1.
Verdict: Since C_in ≠ C_out (and true sum -135 < -128), Signed Overflow OCCURS.
Numerical 3: Binary to Gray Code Conversion Problem: Convert Binary 10110_2 to Gray code.
Rule: Keep MSB unchanged; each next Gray bit = XOR of adjacent Binary bits.
G4 = 1, G3 = 1⊕0 = 1, G2 = 0⊕1 = 1, G1 = 1⊕1 = 0, G0 = 1⊕0 = 1 → 11101 (Gray).
Numerical 4: IEEE 754 32-bit Floating-Point Encoding Problem: Encode -13.625 in IEEE 754 Single Precision (Hex).
Steps: Negative → S = 1. 13.625 = 1101.101_2 = 1.101101 × 2^3. Biased Exponent E = 3 + 127 = 130 = 10000010_2. Mantissa M = 10110100000000000000000.
Result: 1100 0001 0101 1010 0000 0000 0000 0000 = 0xC15A0000.
Numerical 5: Hamming Code Parity Bits Calculation Problem: How many minimum redundant parity bits r are required to protect an 8-bit data word using single-error-correcting Hamming code?
Formula: 2^r ≥ m + r + 1 (here m = 8).
Try r = 3: 2^3 = 8 < 8 + 3 + 1 = 12 (fails). Try r = 4: 2^4 = 16 ≥ 8 + 4 + 1 = 13 (holds!).
Answer: 4 parity bits (total 12-bit codeword, placed at positions 1, 2, 4, 8).
Numerical 6: Memory Addressing & Chip Count Problem: A byte-addressable server has 16 MB RAM constructed from 512K × 8 chips. Find address lines and chip count.
Solution: 16 MB = 2^4 × 2^20 = 2^24 bytes → 24 address lines.
Chips = (16 × 1024 KB) / 512 KB = 16384 / 512 = 32 chips.
Numerical 7: CPU Time, MIPS & Amdahl's Law Problem: A 2 GHz CPU runs 10^9 instructions at CPI = 2.5. A crypto accelerator speeds up 40% of runtime by 4×.
Solution: Exec Time = (10^9 × 2.5) / (2 × 10^9) = 1.25 s; MIPS = 2000 / 2.5 = 800 MIPS.
Amdahl Speedup S = 1 / [(1 - 0.4) + 0.4/4] = 1 / 0.7 = 1.43×.
Numerical 8: Direct-Mapped Cache Tag / Index / Offset Split & EAT Problem: A 32-bit byte-addressable CPU has a 64 KB direct-mapped cache with 64-byte blocks. Find Tag, Index, and Block Offset bits.
Solution:
• Block Offset = log2(64) = 6 bits.
• Number of Cache Lines = 64 KB / 64 B = 1024 = 2^10 → Index = 10 bits.
• Tag = 32 - (10 + 6) = 16 bits.

2.7 Banking & SIDBI Hardware Infrastructure (RAID, HSM, ECC & DR)

Descriptive Edge
RAID Level Mechanism Min Disks Fault Tolerance Usable Capacity (N disks) Banking Use Case
RAID 0 Striping (no redundancy) 2 0 disks (any failure loses all) 100% (N) Never for CBS; temp scratch only
RAID 1 Mirroring 2 1 disk per mirror pair 50% (N/2) OS boot drives, small critical logs
RAID 5 Striping + Distributed Single Parity 3 1 disk failure (N - 1) / N Read-heavy archival & document stores
RAID 6 Striping + Dual Distributed Parity 4 2 simultaneous disk failures (N - 2) / N Large compliance / audit log arrays
RAID 10 (1+0) Mirrored pairs striped together 4 1 disk per mirrored pair 50% (N/2) Gold standard for CBS OLTP RDBMS (high random write IOPS, fast rebuild)
  • Hardware Security Modules (HSM): FIPS 140-2/140-3 tamper-evident cryptographic appliances storing root CA keys, payment signing keys, and PIN verification keys in protected silicon—zero plaintext key export.
  • ECC Server RAM (SEC-DED): Banking servers mandate Error-Correcting Code DRAM using extended Hamming codes to correct 1-bit errors and detect 2-bit errors silently in hardware, preventing ledger corruption.
  • Tier III/IV Data Centres & BCP/DR (RBI AIFI Tech Risk & Resilience Directions 2026): AIFIs maintain Primary Data Centres (PDC) and geographically separated Disaster Recovery (DR) sites in distinct seismic zones, tested periodically against strict RPO (Recovery Point Objective — max data loss) and RTO (Recovery Time Objective — max downtime).

2.8 5-Minute Rapid Revision Sheet (25 High-Yield One-Liners)

Last-Day Cram
  1. Generations: 1st Vacuum Tubes → 2nd Transistors → 3rd ICs → 4th VLSI Microprocessors → 5th ULSI/AI/Quantum.
  2. Address Bus = unidirectional (CPU → Mem/IO); Data Bus = bidirectional; k lines address 2^k locations.
  3. PC = address of NEXT instruction; IR = CURRENT instruction; MAR = target RAM address; MDR = data word.
  4. Von Neumann Bottleneck = shared memory/bus for instructions & data; modern CPUs use Modified Harvard (split L1i/L1d).
  5. RISC = fixed-length, Load/Store, hardwired CU, many registers; CISC = variable-length, microprogrammed CU.
  6. DMA transfers bulk I/O blocks directly to RAM bypassing CPU (Burst Mode & Cycle Stealing).
  7. 2's Complement n-bit range: -2^(n-1) to +(2^(n-1)-1); ONE zero; signed overflow iff C_in ≠ C_out at MSB.
  8. Excess-3 is unweighted and self-complementing; Gray Code is unit-distance (adjacent codes differ by 1 bit).
  9. ASCII = 7-bit (128 chars); '0'=48, 'A'=65, 'a'=97; UTF-8 = 1–4 bytes, ASCII-compatible.
  10. Hamming distance: detect t errors → d_min ≥ t + 1; correct t errors → d_min ≥ 2t + 1.
  11. Hamming parity bit count: 2^r ≥ m + r + 1; parity bits sit at powers of 2 (1, 2, 4, 8...).
  12. IEEE 754 Single (32-bit): 1 S | 8 E (Bias 127) | 23 M; Double (64-bit): 1 S | 11 E (Bias 1023) | 52 M.
  13. IEEE 754 special: E=all 1s, M=0 → ±∞; E=all 1s, M≠0 → NaN; BFloat16 keeps FP32's 8-bit exponent for AI.
  14. Banks avoid binary float for currency (0.1 + 0.2 ≠ 0.3); use fixed-point DECIMAL / BigDecimal.
  15. SRAM = 6T flip-flop, no refresh, CPU Cache; DRAM = 1T1C capacitor, needs refresh, Main RAM.
  16. EPROM = UV-erased; EEPROM = byte-level electrical erase; Flash = block-level electrical erase (NOR=XIP, NAND=SSD).
  17. Write-Back cache uses a Dirty Bit and writes to RAM only on eviction; Write-Through updates RAM immediately.
  18. Direct-Mapped Cache: Offset = log2(BlockSize), Index = log2(Lines), Tag = Addr - Index - Offset.
  19. NAND gate counts: NOT(1), AND(2), OR(3), XOR(4), XNOR(5). NOR counts: NOT(1), OR(2), AND(3), XNOR(4), XOR(5).
  20. Full Adder = 2 Half Adders + 1 OR gate; MUX is a universal combinational logic block.
  21. Master-Slave JK Flip-Flop eliminates the Race-Around Condition when J=1, K=1.
  22. CPU Execution Time = (IC × CPI) / Clock Rate; Amdahl's Law = 1 / [(1 - f) + f / k].
  23. Hierarchical Cache EAT = h · Tc + (1 - h) · (Tc + Tm).
  24. RAID 5 (min 3 disks, 1 failure), RAID 6 (min 4 disks, 2 failures), RAID 10 (min 4 disks, best CBS OLTP IOPS).
  25. ECC RAM = SEC-DED (corrects 1-bit, detects 2-bit errors); HSM = FIPS-certified hardware key vault.
