10.3 Cache 3Cs, Flynn's Taxonomy & Multiprocessor Cache Coherence (MESI)

  • The 3 Cs of Cache Misses: (1) Compulsory (Cold) Miss — very first access to a block (reduced by larger block size / prefetching); (2) Capacity Miss — cache too small to hold working set (fixed only by larger cache); (3) Conflict (Collision) Miss — multiple blocks map to same set in Direct/Set-Associative cache (eliminated by Fully Associative or higher k-way associativity!).
  • Flynn's Taxonomy (4 Architectures): SISD (classic single-core CPU), SIMD (one instruction operates on vector/matrix data simultaneously — GPUs, Intel AVX-512, AI tensor units), MISD (rare — fault-tolerant space-shuttle voting systems), MIMD (modern multi-core servers, distributed cloud clusters).
  • SMP (UMA) vs. NUMA: In UMA / SMP, all cores experience uniform latency to shared RAM. In NUMA (Non-Uniform Memory Access — multi-socket enterprise servers), each CPU socket has fast local RAM and slower remote RAM across interconnect.
  • Cache Coherence — MESI Protocol (Snooping): Keeps private per-core L1/L2 caches consistent across cores using 4 states: Modified (dirty, exclusive to this cache), Exclusive (clean, only in this cache), Shared (clean, present in ≥2 caches), Invalid (stale, must fetch).

10.5 SDN (Software-Defined Networking), NFV, SD-WAN & VXLAN

High Paper III Descriptive & MCQ Yield
  • SDN Architecture: Programmatically decouples the Control Plane (routing/policy intelligence centralized in an SDN Controller) from the Data / Forwarding Plane (high-speed commodity switches). • Southbound API: Controller ↔ Switches (OpenFlow, NETCONF, BGP-LS).
    • Northbound API: Controller ↔ Business/Security Apps (REST APIs).
  • NFV (Network Functions Virtualization): Replaces dedicated proprietary hardware appliances (firewalls, NAT gateways, IPS, load balancers) with software Virtual Network Functions (VNFs) running on standard x86 servers/containers. (SDN = separates control/data plane; NFV = virtualizes network appliances—they complement each other!)
  • SD-WAN: Applies SDN to wide-area branch links, dynamically steering traffic across MPLS, broadband, and 5G based on real-time latency/jitter SLAs.
  • VXLAN (Virtual Extensible LAN): Encapsulates Layer-2 Ethernet frames inside Layer-3 UDP (Port 4789) packets, expanding segmentation from 4,094 VLANs (12-bit) to 16.7 million VNIs (24-bit) for multi-tenant clouds.

10.6 High Availability: L4 vs. L7 Load Balancers, Reverse Proxies & CDN

  • L4 vs. L7 Load Balancing: L4 (Transport): Routes based on IP + TCP/UDP port (ultra-low latency, no TLS decryption). L7 (Application): Inspects HTTP URL paths (/api/loans vs. /static), headers, cookies; performs TLS termination, sticky sessions, and WAF filtering.
  • Forward Proxy vs. Reverse Proxy: Forward Proxy sits in front of Clients (enforces corporate web filtering, caches outbound traffic, hides client IP). Reverse Proxy (Nginx, HAProxy, F5) sits in front of Backend Servers (hides origin IPs, balances load, offloads TLS, mitigates DDoS).
  • CDN & BGP Anycast: Caches static/edge assets at globally distributed PoPs; Anycast advertises the same IP prefix from multiple PoPs so BGP routes users to the topologically closest edge node.

10.7 Worked Exam Numericals (7 Step-by-Step Architecture Problems)

2-Mark Scoring Zone
Numerical 1: Pipeline Speedup with Latch Overhead Given: Non-pipelined CPU latency = 50 ns. Converted to k = 5 stages with stage delays 8, 10, 9, 12, 11 ns + latch delay 2 ns. Find pipeline clock cycle & steady-state speedup.
Pipeline Cycle: t_p = max(stage) + latch = 12 + 2 = 14 ns.
Steady-State Speedup (n → ∞): 50 / 14 = 3.57×. (For n = 100 instructions: (5 + 100 - 1) × 14 = 1456 ns vs. 5000 ns).
Numerical 2: Effective CPI with Branch Hazards Given: Ideal CPI = 1; 20% instructions are branches; branch predictor accuracy = 75%; misprediction penalty = 3 stall cycles.
Misprediction rate: 25% of 20% = 0.05.
Effective CPI: 1 + (0.20 × 0.25 × 3) = 1 + 0.15 = 1.15.
Numerical 3: 4-Way Set-Associative Cache Address Split Given: 32-bit address, 64 KB 4-way set-associative cache, 64 B block size.
• Block Offset = log2(64) = 6 bits.
• Total lines = 64 KB / 64 B = 1024. Sets = 1024 / 4 = 256 = 2^8 → Set Index = 8 bits.
• Tag = 32 - (8 + 6) = 18 bits.
Numerical 4: Big-Endian vs. Little-Endian Byte Storage Value: 32-bit hex word 0x12345678 stored at addresses 0x100..0x103.
• Big-Endian (Network): 0x100: 12 | 0x101: 34 | 0x102: 56 | 0x103: 78.
• Little-Endian (x86): 0x100: 78 | 0x101: 56 | 0x102: 34 | 0x103: 12.
Numerical 5: Instruction Word Bit Allocation Given: 16-bit instruction supporting 32 distinct opcodes and 1 register operand + 1 memory address. Machine has 16 registers. Find max addressable memory words.
Bits used: Opcode = log2(32) = 5 bits; Register = log2(16) = 4 bits.
Remaining address bits = 16 - (5 + 4) = 7 bits → Max memory = 2^7 = 128 words.
Numerical 6: Leaf-Spine Clos Fabric Links A banking DC builds a full-mesh Leaf-Spine fabric with 4 Spine switches and 12 Leaf switches (1 uplink per Leaf-Spine pair).
Total inter-switch links = 4 × 12 = 48 active ECMP links (0 blocked by STP!).
Numerical 7: Parallel High-Availability System Reliability Two redundant L7 Load Balancers each have 99% (0.99) availability deployed in Active-Active parallel mode.
Combined Availability: 1 - (1 - 0.99)(1 - 0.99) = 1 - 0.0001 = 99.99% ("Four Nines")!

10.8 Banking & SIDBI Data Centre Context + 10-Mark Blueprint

Descriptive Edge

Enterprise financial data centres hosting SIDBI's digital platforms combine Leaf-Spine SDN fabrics (for zero-trust East-West micro-segmentation), Active-Active L7 load balancers, and SAN Synchronous Replication (RPO ≈ 0) between Primary DC (PDC) and Near-DR plus Asynchronous Replication to distant DR—aligned with RBI AIFI Cybersecurity, Technology: Risk, Resilience and Assurance Framework Directions, 2026.

Paper III (Part B) 10-Mark Descriptive Model Blueprint Probable Question: "Compare Software-Defined Networking (SDN) and Network Functions Virtualization (NFV), and explain how Leaf-Spine topologies and L7 Load Balancers improve resilience in modern banking data centres." (10 Marks | 200 Words)
• Intro (25w): Legacy 3-tier hardware-bound networks suffer STP bottlenecks, slow manual VLAN provisioning, and lateral-movement risk.
• SDN vs. NFV (75w): SDN separates Control Plane (central OpenFlow controller) from Data Plane for dynamic zero-trust micro-segmentation; NFV virtualizes firewalls/WAFs/IDS as elastic VNFs on commodity servers.
• Leaf-Spine & L7 HA (80w): Clos Leaf-Spine uses L3 ECMP for deterministic 2-hop East-West latency with zero blocked links; Active-Active L7 load balancers add TLS termination, health-checked failover, and DDoS absorption.
• Conclusion (20w): Together they deliver agile, RBI-resilient PDC–DR architecture for high-volume MSME digital lending.

10.9 5-Minute Rapid Revision Sheet & 15 Exam-Level Practice MCQs

Last-Day Cram + Drill
  1. Indexed addressing = arrays; PC-Relative = relocatable branches / PIC; Indirect = pointers (2 RAM refs).
  2. Big-Endian = MSB at lowest address (Network Byte Order); Little-Endian = LSB at lowest address (x86).
  3. Classic 5-Stage RISC Pipeline: IF → ID → EX → MEM → WB; Total cycles = k + n - 1.
  4. Pipeline clock period = max(stage delay) + latch delay.
  5. Structural Hazard = hardware conflict (fixed by split L1i/L1d Harvard cache).
  6. RAW = True Data Dependency (fixed by Operand Forwarding/Stalls); WAR & WAW = False Dependencies (eliminated by Register Renaming!).
  7. Control Hazard = branches (mitigated via 2-bit Dynamic Branch Prediction & BTB).
  8. Cache 3 Cs: Compulsory (Cold), Capacity, Conflict (Conflict eliminated by Fully Associative cache).
  9. Flynn's Taxonomy: SIMD = GPUs/vector AI units; MIMD = multi-core servers & clusters.
  10. MESI Cache Coherence states: Modified, Exclusive, Shared, Invalid.
  11. NUMA = faster access to local socket RAM than remote socket RAM.
  12. Legacy 3-Tier DC uses STP (blocks links); modern Leaf-Spine (Clos) uses L3 ECMP (all links active, fixed 2-hop East-West).
  13. SAN = Block-level (Fibre Channel, iSCSI — CBS RDBMS); NAS = File-level (NFS, SMB).
  14. SDN decouples Control Plane from Data Plane; Southbound API = OpenFlow; Northbound = REST.
  15. NFV virtualizes network appliances (firewalls, IDS, LB) as software VNFs on commodity x86 servers.
  16. VXLAN encapsulates L2 frames in UDP 4789 with 24-bit VNI (16.7 million segments vs. 4,094 VLANs).
  17. L4 Load Balancer routes by IP/Port (fast); L7 Load Balancer inspects HTTP URL/Headers + TLS termination.
  18. Forward Proxy acts for Clients; Reverse Proxy protects/accelerates Backend Servers.
  19. BGP Anycast routes users to the nearest CDN edge PoP using the same IP prefix.
  20. Parallel Availability: A_total = 1 - (1 - A1)(1 - A2); Series Availability: A1 × A2.
  21. Synchronous SAN replication gives RPO ≈ 0 (short distance); Asynchronous spans distant seismic DR zones.
  22. Tomasulo's Algorithm enables Out-of-Order Execution + dynamic register renaming.
  23. Superscalar CPUs issue multiple instructions per clock cycle (CPI < 1).
  24. 0-Address ISA uses an implicit Stack; 3-Address ISA (RISC) keeps source operands unmodified.
  25. SD-WAN dynamically steers banking branch traffic across MPLS/Internet/5G based on live SLA telemetry.
