17.1 Classical AI: Intelligent Agents, Search (A*) & Adversarial Games

AI Foundations
  • PEAS Task Environment: Performance measure, Environment, Actuators, Sensors.
  • Search Algorithms Comparison: • BFS: Complete & optimal (unit step cost), high memory O(b^d).
    • DFS: Low memory O(b · m), NOT complete (loops) & NOT optimal.
    • Iterative Deepening DFS (IDDFS): Combines BFS optimality/completeness with DFS linear space O(b · d)!
    • A* Search: Evaluates f(n) = g(n) + h(n) (path cost so far + heuristic estimate to goal). Guaranteed Optimal iff heuristic h(n) is Admissible (h(n) ≤ h*(n) — NEVER overestimates true remaining cost!).
  • Minimax & Alpha-Beta Pruning: Used in 2-player zero-sum games (Chess). Alpha-Beta pruning skips provably irrelevant subtrees without ever changing the final Minimax decision, cutting time from O(b^m) to O(b^(m/2)) under optimal move ordering.

17.2 Machine Learning Paradigms & Core Algorithms Matrix

Top Paper III Objective Zone
Algorithm Type Core Mechanism Exam Traps & Banking Use
Logistic Regression Supervised Classification Sigmoid σ(z) = 1/(1+e^-z) + Binary Cross-Entropy (Log-Loss) Trap: Despite its name, it is a Classifier! Gold standard interpretable credit scorecard.
Decision Trees (ID3/CART) Supervised (Class/Reg) Splits by Information Gain (Entropy) or Gini Impurity Prone to overfitting unless pruned (max_depth); needs no feature scaling.
Random Forest (Bagging) Ensemble (Parallel) Bootstrap samples + random feature subsets → majority vote Primarily reduces Variance (overfitting) of deep trees!
XGBoost / LightGBM (Boosting) Ensemble (Sequential) Each new weak tree fits residual errors of previous trees Primarily reduces Bias; dominant algorithm on tabular MSME credit & fraud data!
SVM Supervised Classification Finds Maximum Margin Hyperplane; Kernel Trick (RBF/Poly) maps non-linear data to higher dimensions Depends only on Support Vectors; sensitive to feature scaling.
k-NN Supervised (Lazy Learner) Stores data (O(1) train); classifies by majority of k nearest neighbors Slow prediction; suffers Curse of Dimensionality; MUST normalize features!
K-Means Unsupervised Clustering Minimizes intra-cluster variance (WCSS); choose k via Elbow / Silhouette Assumes spherical clusters; sensitive to outliers & random init (use K-Means++).

PCA Unsupervised Dim. Reduction Projects features onto orthogonal Eigenvectors of covariance matrix maximizing variance Linear reduction; MUST standardize features (mean 0, var 1) before PCA!
Reinforcement Learning Sequential MDP Agent maximizes cumulative discounted reward γ via Trial-and-Error (Q-Learning) Key dilemma: Exploration vs. Exploitation (ε-greedy).

17.3 Bias–Variance Trade-Off (SVG), L1/L2 Regularization & Class Imbalance

Guaranteed Concept Trap
  • Underfitting (High Bias): High training error AND high test error (model too simple). Overfitting (High Variance): Very low training error, high test error (memorizes noise).
  • L1 vs. L2 Regularization (Controls Overfitting): • L1 (Lasso): Adds λΣ|w_i| → drives weak feature weights to EXACTLY ZERO (automatic Feature Selection / Sparse model!).
    • L2 (Ridge): Adds λΣw_i^2 → shrinks correlated weights smoothly toward zero without zeroing them out (handles multicollinearity).
  • Imbalanced Datasets (Fraud / NPA = 1–2% Positive): Avoid the Accuracy Paradox! Fix via SMOTE (Synthetic Minority Oversampling — apply ONLY on training fold, NEVER before train/test split to prevent Data Leakage!), class weights, and PR-AUC / F1 / Recall.

17.4 Confusion Matrix, Precision/Recall/F1 & ROC vs. PR-AUC

Guaranteed 2-Mark Numerical
  • Type I Error (False Positive — FP): Flagging a genuine MSME transaction as fraud (customer friction).
  • Type II Error (False Negative — FN): Missing an actual fraudulent/defaulting borrower (direct financial loss!).
  • Core Formulas: • Precision = TP / (TP + FP) (of predicted positives, how many are truly positive?)
    • Recall (Sensitivity / TPR) = TP / (TP + FN) (of actual positives, how many did we catch?)
    • Specificity (TNR) = TN / (TN + FP) • FPR = 1 - Specificity = FP / (FP + TN).
    • F1-Score = 2 · (Precision · Recall) / (Precision + Recall) (Harmonic Mean — penalizes extreme imbalance!).
  • ROC-AUC vs. PR-AUC: ROC plots TPR vs. FPR (0.5 = random, 1.0 = perfect). On highly skewed fraud/NPA datasets (99:1), PR-AUC (Precision-Recall AUC) is far more informative than ROC-AUC!
  • Regression Metrics: MAE (robust to outliers), MSE / RMSE (penalizes large errors heavily), R^2 (proportion of variance explained; Adjusted R^2 penalizes useless added features!).

17.5 Deep Learning: Neural Networks, Activations, CNNs, LSTMs & Transformers

  • Perceptron & Backpropagation: A single-layer Perceptron is a linear classifier (cannot solve non-linear XOR!). Multi-Layer Perceptrons (MLPs) learn non-linear boundaries via Backpropagation (chain rule of calculus) + Optimizers (SGD, Momentum, Adam adaptive learning rate).
  • Activation Functions: Sigmoid (outputs (0,1), suffers Vanishing Gradient), Tanh ((-1,1), zero-centered), ReLU (max(0, x)) (fast, mitigates vanishing gradient; Leaky ReLU fixes "Dying ReLU"), Softmax (output layer for multi-class classification; converts logits into probabilities summing to 1.0).
  • Deep Architectures: CNN (spatial filters + pooling → KYC ID/cheque OCR), LSTM / GRU (gated recurrent units solving RNN vanishing gradient → cash-flow time-series), Transformers (Self-Attention → parallel sequence modeling, LLMs), Autoencoders (bottleneck reconstruction error detects zero-day fraud anomalies!), Dropout (randomly disables neurons during training to prevent overfitting).

17.6 Explainable AI (SHAP / LIME) & MLOps Model Drift (PSI)

Modern Banking AI Governance
  • Explainable AI (XAI): Regulators reject "black-box" credit rejections. • SHAP (SHapley Additive exPlanations): Game-theoretic additive feature attribution providing consistent local AND global explanations.
    • LIME (Local Interpretable Model-agnostic Explanations): Fits a simple interpretable linear surrogate locally around a single prediction.
  • Model Drift Monitoring (MLOps): • Data Drift (Covariate Shift): Input distribution P(X) shifts over time (measured via PSI — Population Stability Index: <0.1 stable, 0.1–0.25 moderate shift, >0.25 critical drift requiring retraining!).
    • Concept Drift: The underlying mapping P(Y|X) changes (e.g., macro interest shock alters MSME default risk for the same turnover).

17.7 Worked Exam Numericals (7 Step-by-Step AI/ML Problems)

2-Mark Scoring Zone
Numerical 1: Confusion Matrix — Precision, Recall & F1-Score Given: Fraud model tested on 1,000 transactions: TP = 80, FP = 20, FN = 20, TN = 880.
• Precision = 80 / (80 + 20) = 0.80 (80%).
• Recall = 80 / (80 + 20) = 0.80 (80%).
• F1 = 2(0.8)(0.8)/(0.8+0.8) = 0.80. Specificity = 880 / 900 = 97.78%.
Numerical 2: Decision Tree Gini Impurity Problem: A node contains 60% Good Loans and 40% Default Loans. Compute Gini Impurity.
Formula: Gini = 1 - (0.6^2 + 0.4^2) = 1 - (0.36 + 0.16) = 1 - 0.52 = 0.48 (max binary Gini = 0.50 at 50/50 split; pure node = 0!).
Numerical 3: Shannon Entropy of a Binary Node Problem: Node has 50% positive and 50% negative samples.
H = -(0.5 log2 0.5 + 0.5 log2 0.5) = -(-0.5 - 0.5) = 1.0 bit (maximum uncertainty; pure node has Entropy = 0).
Numerical 4: A* Search Node Selection Open list has Node A (g=4, h=5) and Node B (g=6, h=2). Which node does A* expand next?
f(A) = 4 + 5 = 9; f(B) = 6 + 2 = 8 → A* expands Node B (lowest f(n)!).
Numerical 5: ReLU vs. Sigmoid Neuron Output Neuron input z = w·x + b = (2)(3) + (-10) = -4.
• ReLU(-4): max(0, -4) = 0. • Sigmoid(0): 1 / (1 + e^0) = 0.5.
Numerical 6: Softmax Probability Check Raw output logits = [0, 0, 0] across 3 risk classes (Low, Med, High).
e^0 = 1 for all 3 → Softmax probabilities = [1/3, 1/3, 1/3] (sums to 1.0).
Numerical 7: k-NN Euclidean vs. Manhattan Distance Distance between MSME feature vectors P(1, 2) and Q(4, 6):
• Euclidean (L2): √((4-1)^2 + (6-2)^2) = √(9+16) = 5.
• Manhattan (L1): |4-1| + |6-2| = 3 + 4 = 7.

17.9 5-Minute Rapid Revision Sheet & 15 Exam-Level Practice MCQs

Last-Day Cram + Drill
  1. A* Search (f = g + h) is optimal iff heuristic h(n) is Admissible (never overestimates).
  2. Alpha-Beta Pruning speeds up Minimax without altering the final chosen move.
  3. Logistic Regression is a Classification algorithm (Sigmoid + Log-Loss), NOT regression!
  4. Bagging (Random Forest) reduces Variance; Boosting (XGBoost/AdaBoost) reduces Bias.
  5. SVM maximizes the margin hyperplane; Kernel Trick (RBF) solves non-linear separation.
  6. k-NN is a lazy learner (O(1) train) that requires feature normalization and suffers Curse of Dimensionality.
  7. DBSCAN discovers arbitrary-shaped clusters and isolates outliers (noise) without needing k.
  8. PCA projects data onto orthogonal eigenvectors maximizing variance (standardize features first!).
  9. Underfitting = High Bias; Overfitting = High Variance.
  10. L1 (Lasso) yields sparse weights (Feature Selection); L2 (Ridge) shrinks correlated weights smoothly.
  11. Apply SMOTE ONLY on the training fold after train/test split to prevent Data Leakage!
  12. Type I Error = FP; Type II Error = FN (missing fraud/default).
  13. Precision = TP/(TP+FP); Recall = TP/(TP+FN); F1 = Harmonic Mean of Precision & Recall.
  14. On skewed 99:1 fraud datasets, prefer PR-AUC over Accuracy or ROC-AUC.
  15. Adjusted R^2 penalizes adding irrelevant predictors to linear regression.
  16. Decision Tree Gini Impurity = 1 - Σp_i^2 (0 = pure, 0.5 = max binary impurity).
  17. Single-layer Perceptron CANNOT solve non-linear XOR.
  18. ReLU (max(0, x)) mitigates Sigmoid's Vanishing Gradient problem.
  19. Softmax converts raw multi-class logits into a probability distribution summing to 1.
  20. LSTM / GRU gates solve the vanishing gradient problem in sequential RNNs.
  21. Dropout randomly zeroes neurons during training to reduce neural-net overfitting.
  22. Autoencoders detect unsupervised anomalies via high reconstruction error.
  23. SHAP (Shapley values) & LIME provide Explainable AI (XAI) for credit decisions.
  24. PSI > 0.25 signals severe Data Drift requiring model investigation/retraining.
  25. Concept Drift = underlying relationship P(Y|X) changes over time.
